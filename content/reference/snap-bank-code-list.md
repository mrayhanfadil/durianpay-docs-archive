### Transfer to Virtual Account

Whether a Virtual Account can receive transfers depends on the configuration set by the issuing bank. This capability is defined by the bank that generates the Virtual Account.

Some banks support transfers to their Virtual Accounts, while others do not. For example, certain BCA Virtual Accounts can receive transfers, but this may not apply to all configurations. Availability must be checked on a case-by-case basis with the issuing bank.

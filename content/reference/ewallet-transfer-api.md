# E-Wallet Transfer API

The following endpoint to submit e-wallet transfer pay outs

> E-Wallet Transfer API will transfer the fund to the destination account based on platformCode and customerNumber only without considering customerName. To ensure correct destination please verify the customerName using E-Wallet Account Inquiry API.

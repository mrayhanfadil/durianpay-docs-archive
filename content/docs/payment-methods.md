# Payment Methods

## Introduction

Durianpay provides a plethora of payment methods that you can choose to be integrated within your platform. With over 20+ payment methods which includes top 5 e-wallets available and more to be coming, Durianpay has the most complete payment methods available in the market to date. Here’s all payment methods available in Durianpay.

| Category          | Payment Method                                |
| :---------------- | :-------------------------------------------- |
| Virtual Account   | BCA, Mandiri, Permata, BNI, BRI, Nobu, Others |
| Credit Card       | Visa, Mastercard                              |
| QRIS              | QRIS                                          |
| E-Wallet          | Gopay, OVO, Dana, Shopeepay, Linkaja          |
| Convenience Store | Indomaret, Alfamart                           |
| Buy Now Pay Later | Indodana                                      |
| Internet Banking  | JeniusPay                                     |

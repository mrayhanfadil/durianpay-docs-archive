Durianpay WooCommerce Plugin enables seamless integration of Durianpay as a payment gateway in your WooCommerce store. Start accepting payments easily with a secure, reliable, and fast checkout process.

## Pre-Requisites

Durianpay's WooCommerce plugin will only be supported for:

* WordPress version 5.6 or higher
* WooCommerce version 4.0 or higher
* PHP version 7.4 or higher

<br />

## Steps Overview

* Step 1: Install the plugin
* Step 2: Configure the woocommerce plugin

### Step 1: Installing the plugin

To install Durianpay's Wocommerce plugin, please download the [file in Durianpay's Github Repository](https://github.com/durianpay/durianpay-woocommerce/raw/refs/heads/master/releases/latest/woo-durianpay.zip)

After you have downloaded the file, you need to upload it into the plugins section of your wordpress account. To do that, you can follow these steps:

1. In your wordpress account, navigate to plugins
2. Press "Add New" button
3. Press "Upload Plugin"
4. Choose the file which you have downloaded from the previous step
5. Done

### Step 2: Configure the WooCommerce

After you have uploaded Durianpay's WooCommerce plugin, you have to configure the plugin before you can start accepting payments from your customer. To do that, you can:

1. Log into your WordPress account and activate the Durianpay plugin in the WordPress Plugin Manager.
2. Log into your WooCommerce account, navigate to Settings and click the Checkout/Payment Gateways tab.
3. Click Durianpay to edit the settings.
4. Enable the Payment Method, name it Credit Card / E-Wallets / Virtual Account (This is shown on the Payment page your customer sees).
5. Add in your \<key\_secret> generated from the Durianpay Dashboard.

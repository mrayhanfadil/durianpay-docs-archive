# IP Whitelisting to secure your API transaction

Ensure only the right party can use your disbursment funds

## What is IP Whitelisting ?

Durianpay's IP Whitelisting feature is an additional layer of security designed to protect your disbursement services from unauthorized access. By enabling IP whitelisting, you can restrict access to your disbursement APIs, ensuring that only requests coming from approved IP addresses can use the disbursement functionality.

This means that even if someone gains access to your API key, they will not be able to use the disbursement feature unless their IP address is explicitly whitelisted. It’s a powerful way to control access and prevent unauthorized transactions, safeguarding your funds and protecting your business from potential risks.

We highly recommend you to provide the IP address list to be white-listed especially if you are using Pay Out/ Disbursement feature to secure your transactions with us.

> 📘 Please inform our operations team (<merchantops@durianpay.id>) your IPs to enable the IP Whitelisting Feature.
>
> Or If you have filled the IP address list in the registration form, it will be directly setup by our operation team.

# Durian Checkout

Modern and beautiful checkout - with batteries included

Durian Checkout is a low-code payment integration that enables a customizable, conversion-optimized checkout experience for your customers. You can embed Durian Checkout directly on your website or redirect users to a secure, Durianpay-hosted payment page. It supports local payment methods and is designed to work seamlessly across devices and browsers, providing a modern, first-class payment experience.

## Low Code Integration

Checkout requires minimal coding and is the best choice for most integrations because of its prebuilt functionalities and customization options. Offering plug-and-play ease for quick setup across platforms. It’s designed to increase payment conversion with an in-app, seamless payment experience.

> 📘 Built-in and Customizable Features in Durian Checkout
>
> * [x] Dynamic Closed Virtual Accounts, eWallet, QRIS, Cards, and Convenience Store
> * [x] Responsive mobile design
> * [x] ISO27001 compliance
> * [x] Card validation
> * [x] Error messaging
> * [x] eWallet Account Binding
> * [x] Custom branding with colors, and buttons
> * [x] Embed in web view
